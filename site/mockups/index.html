One screen, three levels

Every dashboard reworked as an inverted pyramid: an Overview that fits one screen with no scrolling, a left-hand rail to zoom into a topic and its sub-topics, and a drawer for the deepest detail. Toronto City Pulse is built this way already; the other three are mockups using real numbers from each project's data.

  1. Overview fits the screen. Equal-weight tiles, so no topic reads as "the main one". Each tile shows its headline number, a small chart, and links to its sub-topics.
  2. The rail is the map of the dashboard. Topics expand to sub-topics; badges carry each topic's headline number, so it works as a summary too. On phones it becomes tabs.
  3. Detail opens beside the chart, not over it. The drawer docks on the right and the view reflows, so the item you picked stays visible.
  4. Every level has an address. #topic/sub/item keeps links shareable and makes the back button step back up the pyramid.

What would become shared code

Applying it to the others

  • Dark Sky, Hazards, Water, Foliage and Sunday follow the same three levels: one tile per question on the Overview, then topics in the rail.
  • Each project keeps its own colours, fonts and alt skin; only the layout is shared.
